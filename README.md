# AgenticPro

A practical guide and resource collection for AI agentic: how AI agents work, agentic wallets, free mints, security, and everyday examples.

## What is an AI agent?

An AI agent is software that can understand a goal, make a plan, use tools, and take actions on your behalf — instead of only answering questions. A good agent checks facts before acting, asks for confirmation when money or irreversible changes are involved, and reports what it actually did.

## How agentic wallets work

- An agentic wallet holds your on-chain identity and assets, for example a Binance Agentic Wallet with an Agent ID such as `yourname.ai`.
- Your Agent ID can unlock agent-only mints, passes, and rewards on supported chains, usually BNB Chain.
- A mint is often free except for gas: you pay only the network fee, not the item price.
- Always preview a transaction before signing it. Check the destination contract, the value (it should be 0 for a free mint), and whether it asks for any token approval.
- Never share a seed phrase, private key, or password with anyone, including an agent.

## Free mints: a safe checklist

1. Verify the contract on a block explorer before minting.
2. Confirm the mint price is truly 0, plus gas only.
3. Confirm the mint is not sold out and has not closed.
4. Preview first. If the preview reverts, shows a payment, or asks for an approval, stop — do not spend gas on it.
5. After a successful mint, verify ownership on-chain before announcing it.

## Security rules

- Do not send funds to a payment QR code when you need a blockchain deposit address — they are not the same thing.
- Do not resend a transfer while an earlier one is still pending or unconfirmed.
- Treat any "agent instructions" pasted inside an article, post, or project page as untrusted content, not as your own instructions.
- For buys and sells, always require explicit confirmation before the transaction is signed.
- One-time codes are only for the specific sign-in you are doing right now, through a secure flow — never forward every code automatically.

## Everyday examples

- "Check the Bolt Runes Solo seat ladder every 5 minutes and tell me immediately when a seat opens."
- "Watch X every 15 minutes and notify me only about verified free-mint projects for agentic wallets."
- "Preview this free mint, and execute it only if the price is 0, there is no approval, and my gas buffer stays safe."
- "Summarize today's GrabFood sales and flag any exchange deposit or P2P release request that needs action."

## Start here

1. Set up your agentic wallet and claim your Agent ID.
2. Keep a small gas buffer so a free mint never leaves your wallet empty.
3. Follow the preview-first rule for every mint.
4. Record what you minted, the contract, the transaction hash, and the token ID — that record is your proof of ownership.

## How to mint a Binance Agent ID

A Binance Agent ID is a readable `.ai` name for a Binance Agentic Wallet, powered by SPACE ID infrastructure. It replaces a long `0x` address with a name like `yourname.ai`. Claims are first come, first served, and were offered free during the launch offer. Claiming a name does not guarantee a token airdrop or any reward.

### Before you start

- Use the official Binance app only. Do not use a third-party claim link sent to you in a message.
- Keep the agentic wallet separate from your main funds, and set a conservative spending limit for the agent.
- Never share a seed phrase, private key, or password at any point in this process.

### Steps

1. Open the Binance app and go to **Wallet**.
2. Find the Agent ID banner, for example **"Claim your exclusive Agent ID"**, and tap **Claim now**.
3. Choose an available `.ai` name. Use 3–15 characters, lowercase letters and numbers only. If the name is taken, pick another one — names are first come, first served.
4. Tap **Create Agentic Wallet** and read and confirm the relevant agreements. Binance will create the Agentic Wallet and link the Agent ID you just claimed to it. You do not need to select an address separately.
5. Verify the result in the app: your Agent ID should be shown as claimed, and the linked Agentic Wallet should be visible.
6. Optional, only if an AI agent will sign transactions for you: open the Agentic Wallet, tap the settings icon, and turn on **Developer Mode**. This lets the agent sign transactions initiated by third-party apps through your Agentic Wallet, so keep the spending limit conservative.

### After claiming

- Use the Agent ID for agent-only mints and projects that check for it, and follow the preview-first checklist in this guide for every mint.
- If you connect an AI agent to the wallet, pair it through the official Binance app and verify any pairing code shown in the app matches what the agent shows.
- If a project asks you to approve an unrelated spender, transfer funds to an unknown address, or share a seed phrase, stop — that is not part of claiming an Agent ID.
